# SPECTRAL SCORE

Локальное веб-приложение для просмотра предполагаемых нот в аудиозаписи.

## Запуск

Требуется актуальный Chromium-браузер и Node.js 20.19+ или 22.12+.

```bash
npm install
npm run dev
```

Откройте адрес, который выведет Vite, в Chromium.

## Docker

Собрать production-образ и запустить приложение на порту `8080`:

```bash
docker build -t spectral-score .
docker run --rm -p 8080:8080 spectral-score
```

После запуска откройте [http://localhost:8080](http://localhost:8080). Контейнер только раздаёт собранный клиент: аудио и анализ по-прежнему остаются в браузере.

## Ограничения и приватность

Аудио не покидает устройство: декодирование и анализ выполняются в браузере. Поддерживаются файлы, которые Chromium способен декодировать, размером до 200 МБ и длительностью до 10 минут.

Результат Basic Pitch — это оценка высоты и длительности нот, а не точная партитура. Шум, несколько инструментов, вокал и сложная аранжировка могут заметно снизить точность.

## Лицензии

Для анализа используется [Basic Pitch](https://github.com/spotify/basic-pitch) от Spotify. Его модель, лицензия Apache-2.0 и требуемая атрибуция находятся в `public/models/basic-pitch/ATTRIBUTION.md` и `public/models/basic-pitch/LICENSE`.
